# Support

Thank you for using Codex for Home Assistant. I maintain this project with help from community reports and contributions.

## Getting Help

Start with the project documentation:

- [README](README.md) for installation, setup, security notes, and examples.
- [Integration documentation](custom_components/codex_cli/README.md) for entities and actions.
- [Worker documentation](codex-cli-worker/DOCS.md) for app options and behavior.
- [Verification guide](codex-cli-worker/VERIFICATION.md) for dashboard screenshots, permissions, and limits.
- [Example scripts](examples/scripts.yaml) for a starter Assist/LLM script.

## Reporting Bugs

Use the [bug report template](https://github.com/moryoav/home-assistant-codex/issues/new?template=bug_report.yml) when something is not working as expected.

Please include:

- Both the worker app and Codex integration versions.
- Your Home Assistant version.
- Your installation method.
- Your architecture, such as `amd64` or `aarch64`.
- Clear reproduction steps.
- Relevant logs with sensitive information removed.

Do not include secrets, tokens, device codes, private URLs, personal paths, or private Home Assistant configuration.

## Feature Requests

Use the [feature request template](https://github.com/moryoav/home-assistant-codex/issues/new?template=feature_request.yml) for new ideas or improvements.

Please explain the Home Assistant workflow you want to improve and whether you think the change belongs in the worker app, the custom integration, or both.

## Security Issues

If you believe you found a security vulnerability, do not open a public issue with exploit details. Follow [SECURITY.md](SECURITY.md).

## Scope of Support

I cannot guarantee an immediate reply. Please keep backups of your Home Assistant configuration and review changes Codex makes before relying on them.
